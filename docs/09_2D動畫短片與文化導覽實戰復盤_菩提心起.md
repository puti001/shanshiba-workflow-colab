# 09 2D 動畫短片與文化導覽實戰復盤（以《菩提心起：佛陀教我做導覽》為例）

本文件整理《菩提心起：佛陀教我做導覽》（14 鏡、2D 賽璐珞手繪風格、佛陀紀念館文物導覽題材）從早上開案到成片交付過程中所採用的**新技術方案、9:16 滿版智慧導播運鏡、9 大實戰踩坑、根因剖析、解決方案與下一支片的前置防呆建議**。

## 一、 本次採用的新技術與工作流升級

### 1. PDF 展品知識庫與真實視覺錨點自動萃取
* **做法**：利用 PyMuPDF (`fitz`) 直接從策展手冊（`展品資料.pdf`）與現場場勘（`展場影片截圖.pdf`）自動抽取出 29 張高清文物圖與 23 張展廳實景圖，建立文物結構描述表（如黃土水〈釋迦出山〉蓄鬍赤足、北齊〈張解造像碑〉碑底供養人、宋代〈泥塑加彩羅漢〉深邃眼窩與微蹙眉頭）。
* **效益**：生圖 Prompt 不再憑空想像佛像外觀，而是 100% 錨定真實館藏文物特徵。

### 2. 「單張滿版 16:9 原生構圖 ＋ 同對話串接續編輯（In-Thread Edit）」取代雙聯畫分割
* **痛點**：傳統「左右雙聯圖（2-panel side-by-side）」塞進一張橫圖時，單格比例會被迫變成接近正方形，切回 `16:9` 時上下會被裁掉 40%，或導致雙人＋中間展櫃放不下。
* **新做法**：
  * **單幀鏡（6 鏡：`S01, S03, S05, S09, S11, S12`）**：直接生單張滿版 `16:9` 首幀，`use_last: false`，靠 H3 的 `action` 與 `LOCKED-OFF STATIC CAMERA` 演繹自然動作。
  * **首尾鎖定鏡（8 鏡：`S02, S04, S06, S07, S08, S10, S13, S14`）**：先生成滿版 `16:9` 首幀，再於**同一個生圖對話串**下達「保留 100% 相同展廳背景與機位，只改角色動作成尾幀」的接續指令。
* **實測成果**：背景鎖定率 100%，完全消除雙聯圖比例裁切與左右格光影不一致的問題。

### 3. 16:9 母帶 ➔ 9:16 滿版智慧導播運鏡（Sub-pixel Smart Pan & Scan Virtual Camera）
* **核心技術（`make_vertical_panscan.py`）**：
  * 不使用傳統上下加模糊黑邊的縮小版，而是直接從 `1920×1080` 母帶取樣 `9:16` 視窗並放大至滿版 `1080×1920`。
  * **次像素雙三次插值（Sub-pixel Bicubic Extent Transform）**：放棄 FFmpeg 整數像素 `crop`（會有明顯階梯跳動感），改用 PIL `Image.Transform.EXTENT` 浮點座標插值＋`0.5 - 0.5 * cos(π * p)` 餘弦緩動（Cosine Ease-In-Out），達成如滑軌般順暢的橫搖（Pan）與推軌（Zoom）。
  * **「定格（Hold）➔ 緩移（Pan）➔ 定格（Hold）」導播結構**：先鎖定說話角色、再橫移至中央文物特寫、最後搖至聽眾反應。
  * **42 格 9:16 實拍檢視總表（`inspect_vert.py`）**：將 14 鏡各抽 `15%, 50%, 85%` 三格拼成 `vert_panscan_check.jpg`，用肉眼逐格審查是否切到人物半邊臉。

### 4. 依標點分段之「單行序列字幕」（Sequential Single-Line ASS Subtitles，每行 ≤ 20 字）
* **鐵律**：**畫面一次只呈現 1 行字幕，嚴禁一次呈現 2 行（禁止使用 `\N` 雙行堆疊），且每行含角色名稱嚴格 ≤ 20 字**。
* **做法**：使用 `split_sub_clauses(role_name, text, t_start, t_end, max_len=20)` 依標點符號（`，。？！、：…`）將長句拆分為 2～4 段獨立單行子句，並依各段有效字數比例動態分配 `[t_start, t_end]` 時間區間。
* **效益**：視覺乾淨不遮擋畫面底部細節、閱讀節奏自然跟隨語音推進，且在 `16:9` 與 `9:16` 雙比例下皆絕不貼邊或切字。

## 三、 給下一支片的 7 條黃金防呆建議（省時、省額度、一次過關）

1. **【Gate 1 鐵律】6.5 秒鏡頭台詞嚴禁超過 25 個中文字**
   * 在寫 `build_film_v3.py` 階段，由 `lint_v3.py` 強制檢查：`len(clean_text) <= 25`（每秒 `3.8～4.2` 字）。
   * 這一條能同時解決**「語速過快」、「H3 尾字念不完被切」、「後製被迫套 `atempo` 加速」**三大問題，從源頭根除！
2. **【字幕鐵律】適當斷句、每行嚴格 ≤ 20 字、絕不一次呈現 2 行**
   * 所有專案統一使用 `split_sub_clauses(role_name, text, t_start, t_end, max_len=20)`，按標點將長句切分為多段依序顯示的**單行字幕**（嚴禁使用 `\N` 雙行堆疊）。
3. **【9:16 滿版運鏡鐵律】單鏡最多 2 焦點緩移、跨區大跳改用「鏡內切鏡（In-shot Cut）」、必看 `vert_panscan_check.jpg`**
   * 單鏡只做「單人鎖定微推」或「A ➔ B 兩點慢速滑移（過渡時間 ≥ 2.5s）」；若水平距離超過 `0.45`（如從最左老師到最右遊客），直接按台詞切點做 **直式分鏡硬切（Virtual Multi-cam Cut）**，徹底消除快移眩暈感！
   * 每次產出 9:16 必跑 `inspect_vert.py` 並親眼檢查 42 格抽幀表。
4. **【省 Token 鐵律】本機 CPU 跑 VoxCPM2 一次載入模型批次生完，不在對話迴圈裡單句重跑**
   * 本機無獨顯（CPU 模式）跑 VoxCPM2 每句需 60～90 秒，應在 Gate 2 跑完一次 Whisper `word_timestamps` 後，列出所有需補錄的鏡號，寫成**單一批次腳本（只載入一次模型）**一次跑完。
5. **【對嘴鐵律】生圖與 `action` 明確指定唯一開口角色：`Only [Character] speaks; others nod with closed mouths`**
   * 多人同鏡時，務必在 `action` 寫明誰開口說話、誰閉嘴點頭微笑，並確保 `line.who` 與畫面開口者 100% 對應。
6. **【音質統一鐵律】H3 原聲與補錄 TTS 必須過同一個「頻譜明亮度正規化（Spectral Matching）」**
   * 混音前自動計算每句 `>3.5kHz` 頻譜能量佔比，若 H3 原聲低於 `25%`，自動掛載 `equalizer=f=3500:g=6.5,treble=g=8.5:f=6000` 提亮，禁止直接套 `lowpass` 或重度 `afftdn`。
7. **【自審鐵律】`fix_v3_cut.py` 結尾強制輸出「12 鏡字幕 vs Whisper 實聽對照表」**
   * 任何一次合成或修改音軌後，腳本必須自動跑完 Whisper 轉寫並比對 `film.json` 字幕，不再依賴肉眼猜測或漏加 `--asr`。


### 10. 尾幀必要性審核與特寫空鏡彈性運用（不硬性限額）
- **尾幀按需生成（審核必要性，不設硬性數量上限）**：不強行限制尾幀數量，該生尾幀的鏡頭（如背影轉正臉、跨空間跳躍/顯化、精準道具/姿態結果鎖定）就生尾幀；一般原地對話或微幅反應則維持 `use_last: false`，在排定 `film.json` 時逐鏡審核「這一鏡是否真的需要尾幀」，並將有尾幀的鏡頭拼成 `first vs tail` 對照圖審查。
- **彈性穿插特寫／物件插入鏡（Insert Shot，選用）**：視劇情需要，可適時穿插手部動作特寫、文物局部特寫或環境空鏡（角色台詞轉為畫外音 VO），既能豐富視覺景別，也能在長句解說時自然避開嘴型對位壓力，但不強行規定每片必塞幾鏡。


### 11. 角色參考資產、場景母版與實體動態提示詞黃金法則（實戰去虛就實）
- **角色參考圖嚴禁多視圖同框拼貼**：
  - 生首幀與進影片模型（如 H3）時，**永遠只給「單張乾淨背景、正面／微側 45 度、表情放鬆」的高清定妝照**。
  - 嚴禁把正面＋背面或表情九宮格拼成一張圖當參考圖（影片模型會注意力混淆，產生後腦勺長臉或服裝正反拉鍊錯亂的畸形）。
- **真實空間母版（Spatial Master）定錨**：
  - 嚴禁純文字虛擬描述特定場館（如「莊嚴展廳」）；一律以一張真實高清場景母版圖為底，並在同對話串接續編輯（In-Thread Edit）維持全片展櫃、光影與地板材質 100% 連戲。
- **具體物理動態取代抽象情緒詞**：
  - 嚴禁使用 `cinematic lighting`、`masterpiece` 等無效毒藥詞，禁止在正向 Prompt 出現否定句（如 `no pedestrians`）。
  - Action 描述一律遵循物理動作拆解（起點動態、關節彎曲、肌肉發力、位移方向、次數幅度），並以 `Starting from <Picture 1>, ...` 嚴格定錨首幀。


### 12. 格式交付定義：「手機版」唯一指名 9:16 滿版智慧導播運鏡版
- **使用者稱「手機版」、「直式版」**：**唯一指名 `9:16` 滿版智慧導播運鏡成片（1080×1920 Sub-pixel Smart Pan & Scan）**。
- **嚴禁重複生成 2 個版本**：不要再生產上下黑邊/縮放的 720p 橫式手機版或舊式直式版。全片交付規格鎖定為兩支：
  1. **劇院母片版**（`16:9` 1080p，例如 `film_1080p.mp4`）
  2. **手機版**（`9:16` 1080×1920 滿版智慧導播運鏡版，例如 `film_9x16_panscan.mp4`）


### 13. 字幕排版標準規格：大字號（2倍高視覺）與手機版 70% 中間安全區
- **字幕字型大小全面放大**：
  - **16:9 劇院母片**：Fontsize 由 54 升級至 **88~96**（接近原先 2 倍視覺高度），Outline 6、Shadow 2、底部邊距 MarginV 70。
  - **9:16 手機滿版**：Fontsize 由 46~48 升級至 **80~84**，Outline 7、Shadow 3。
- **手機版左右安全邊界（螢幕中間 70% 居中原則）**：
