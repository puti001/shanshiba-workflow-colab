## 二、 核心踩坑記錄與解決之道

### 1. ASS 字幕首幀時間負數 Bug
- **現象**：`out/post/subs.ass` 首行出現 `Dialogue: 0,-1:59:59.95,0:00:03.42,huang...`，導致播放器解析時第一句字幕直接消失。
- **原因**：`make_film.py` 中 `a = l["film_start"] - 0.05`，當台詞從 `0.0` 秒開始時，`a = -0.05`，在 Python `ass_time(-0.05)` 中計算 `int(-0.05 // 3600)` 得到 `-1`，分秒折算為 `59:59.95`。
- **修復**：改為 `a = max(0.0, l["film_start"] - 0.05)`。

### 2. 無台詞鏡頭「全片純 BGM 啞巴」
- **現象**：S04（紫雷轟擊）、S06（暗黑腐蝕）、S08（機甲重拳互轟）、S09（反撲衝擊）、S11（全校分類）、S13（泰坦崩解）等核心戰鬥高潮鏡頭完全沒有音效。
- **原因**：剪輯流程中 `-an` 剔除了影片原生音軌，且 `film.json` 未指定 `amb` 或引入外部 `sfx`，導致混音矩陣振幅為 0。
- **解決**：無台詞鏡頭必須在 `film.json` 標記 `"amb": true` 另跑原生音效，或在後製階段掛載 `sfx_library/`（打擊聲、金屬斷裂、雷聲、能量充能）。

### 3. H3 原生台詞胡言亂語（`h3_ref` 語音幻覺）
- **現象**：H3 在沒有給定固定 TTS 音軌、僅吃參考音時，經常自由發揮胡言亂語：
  - S02 原設定「收到！紙箱工程卡車，出發！」，H3 實際念出「收到謝謝您有穿駕駛車要出發」。
  - S01「小吉」念成「小雞」、「後庄」念成「後中」。
- **解決**：正式成片禁止讓 H3 自發音，應在 `film.json` 全面切回 `"voice_mode": "fixed"`，由 BreezyVoice 生成注音精確標註的台語/台灣國語音軌，或真人錄製音訊注入 `guide.wav`。

### 4. 雙幀極限跨度導致中段「AI 融化泥化」
- **現象**：S02（人形 ➔ 6輪工程卡車）、S11（學生拾荒 ➔ 漫天金光）、S13（泰坦 ➔ 白色粉塵）的中間影格清晰度暴跌 80%～90%（Laplacian 方差由 1900 驟降至 180～300）。
- **原因**：MiniMax H3 的 `frame_idx: -1`（尾幀約束）無法推導跨形態機械摺疊力學，只能進行潛空間 Cross-fade（溶解過渡），造成泥化。
- **解決**：極限姿態切換必須「一分為二」（S02A 翻折下蹲 ➔ S02B 卡車推平），中間插入 0.2 秒機關特寫硬切或白光轉場。

### 5. 跨鏡明暗跳變刺眼（Brightness Jump-cut）
- **現象**：S03➔S04（亮度階躍 40.3）、S12➔S13（階躍 57.1）、S13➔S14（階躍 49.3），切鏡時有刺眼的閃爍感。
- **解決**：在劇烈明暗轉場處，後製剪輯腳本需插入 3～6 格的 White Flash（過曝白閃）平滑視覺過渡。

### 6. 畫風割裂（卡通風 ➔ 真人實拍風漂移）
- **現象**：前半段 S01～S03 偏 3D 插畫卡通質感，後半段操場突然變成高對比 Kodak 膠卷真人寫實電影感。
- **原因**：S01 提示詞與參考圖強調手作紙箱與插畫設定，S04 之後強調 `cinematic live-action photorealistic` 且背景吃真實學校空景相片。
- **解決**：生圖前必須在 `film.json` 鎖死唯一的 `cine` 風格定錨，全片參考圖風格必須統一為真人特攝電影。

### 7. 雙聯圖切 16:9 之構圖裁切
- **現象**：16:9 雙聯圖單幅比例為 834×937（接近 9:10 直立），硬切 16:9 導致上下 50% 畫面遺失。
- **解決**：分鏡生圖提示詞必須指定 32:9 超寬畫幅，或分開生成兩張獨立 16:9。
