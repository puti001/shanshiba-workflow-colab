# 04 自審清單

原則：**交給人看之前，agent 自己先審完、修完**。人只負責主觀判斷（嘴型細節、語氣、好不好笑）。

## review.py 五遍

```
H3 venv:    python review.py cut/<片名>_vN_1080p.mp4          # 第 1、3、4、5 遍
Voice venv: python review.py cut/<片名>_vN_1080p.mp4 --asr    # 第 2 遍
```

| 遍 | 檢查 | 怎麼判斷 |
|---|---|---|
| 1 | 逐鏡抽 4 格拼成總覽圖 | **一定要逐張人工看**：鏡頭漂移、多出人、臉換人、多手多腳、手沒動、背景亂動、老師碰學生、學生面向 |
| 2 | 每句台詞在成片裡 ASR 一次 | 比對分數 <1 的逐句聽；同音同調的辨識字錯不算 |
| 3 | 色度雜訊 | >0.54 **且**比首幀高 25% 以上才警告（畫面本身細節多不算） |
| 4 | 黑畫面、定格（>0.8 秒不動）、響度、峰值 | −15.5 LUFS 左右、峰值 < −1.5 dBFS |
| 5 | 切點前後對照圖、接點明暗差、台詞重疊、台詞被鏡尾切掉 | 明暗差 >12 警告 |

## 常退件清單（人最常抓到的問題）

逐條確認，**不要讓看片的人來抓**：

- [ ] 多腿、多手（踢腿高峰格要看原解析度）
- [ ] 手該動卻沒動
- [ ] 背景的人亂動、突然出現或消失
- [ ] 臉糊、臉換人
- [ ] 接點明暗跳、動作不連貫、硬切
- [ ] 台詞重疊
- [ ] 念錯字、聲調怪、腔調不是台灣腔
- [ ] 道具亂飛（球飛走、紙消失）
- [ ] 多出人（尤其多一個老師）
- [ ] 頭套變老虎、頭套眨眼
- [ ] 黑板或紙上出現亂碼字
- [ ] 上課鏡背景沒有同學
- [ ] 學生沒有面向黑板、窗戶換邊
- [ ] **中間幀畫風突變**（首尾幀是 3D 卡通，中間第 2~4 秒卻變真人實拍或模糊色塊 → 必須抽每鏡 8 格 `dense_part*.jpg` 檢查，不能只看首尾格）
- [ ] **配角／背景學生結冰**（只有主角動、旁邊學生像靜態照片 → 取消該鏡 `use_last` 並重跑）
- [ ] **台詞後半句被腰斬**（角色嘴巴還在動但聲音沒了 → 用 `word_timestamps=True` 重抽完整音軌）
- [ ] **鏡尾 1.5 秒原地發呆或懸空**（動作在 4.2 秒已做完卻拖到 6 秒才切 → 用 `TIGHT_TRIM` 裁掉尾段停滯）
- [ ] **無台詞特效鏡音效太小聲**（各鏡頭 `amb` 需先做峰值正規化再混音）
- [ ] **語速過快像趕火車**（單鏡 6.5 秒台詞超過 26 字，或後製 `if d_raw > max_allowed` 自動套 `atempo` 加速 → 劇本階段限制 ≤25 字；後製若放慢語速，畫面 `stretch` 必須動態由音檔原長 `(d_raw + 0.35) / raw_shot_len` 反推）
- [ ] **前後鏡聲音忽亮忽悶**（混用 H3 原生音軌與外掛 TTS/VoxCPM2 → 禁止對 H3 原聲套 `lowpass`/`afftdn`，必須加 `3.5kHz` 與 `6kHz` 高頻 EQ 拉齊頻譜明亮度）
- [ ] **聲音與字幕不同句／說話者與張嘴者不符**（後製結尾必須強制執行 Whisper ASR 逐句核對 `film.json` 字幕，並核對多人鏡張嘴角色與 `line.who` 是否一致）

## 原則

- **不合格就重拍到合格**，不靠剪掉或插別的鏡頭躲。一批 6 個 seed 常常只有 1 個全過。
- 每支片至少看一張 100% 原尺寸全幀；只看縮圖會漏判雜訊和第三條腿。
- 接點明暗要量成片，不量原始鏡頭（後製會改亮度）。
- 給人看**並排影片**，數字只當備註。人是用眼睛判斷的。
- 技術 QA 通過 ≠ 使用者驗收通過，兩者分開記錄。沒量的東西（例如逐音素對嘴）照實寫「沒量」。
- 回報時用**成片時間碼**對應鏡頭；沒被點名的鏡頭不要動。
